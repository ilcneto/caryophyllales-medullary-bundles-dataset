# Caryophyllales Medullary Bundles Dataset										
A modular dataset within the Plant Vascular Variants Database.						
											
## Overview
This dataset expands upon the "Global Survey of Vascular Variants Across Seed Plants" by providing species-level coding for the occurrence and structural variation of medullary bundles within Caryophyllales.

## Associated Publication
Cunha-Neto IL, Rossetto RFS, Gerolamo CS, Hernández-Gutiérrez R, Sukhorukov AP, Kushunina M, Melo-de-Pinna GFA, Angyalossy A. 2024. [Medullary bundles in Caryophyllales: form, function, and evolution] (https://nph.onlinelibrary.wiley.com/doi/10.1111/nph.19342). New Phytologist 241: 2589-2605.  

## Dataset structure

- ### Family
	Indicates the Caryophyllales family.
- ### Intrafamilial taxa
	Some families have subfamily or clades (classification follows several authors).
- ### Genera
	Indicate the genus name (following POWO 2026).
- ### Species
	Indicate the species name (following POWO 2026). 
- ### Authority
	Indicate species authority.  
- ### Medullary bundles
	Score the presence or absence of medullary bundles.
- ### Source
	Indicate the paper describing stem anatomy, or the source of images used to score medullary bundles. 
- ### References
	Indicate the paper cited in Source.
